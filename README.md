# 青石江湖

离线、低魔的单机文字武侠。“雨夜盐引”序章接续到第六十日的人生终局。所有选择、经济、关系、成长与冲突由本地规则裁决，表达层使用 mock，无真实模型、API Key 或联网游戏功能。

## 启动与验证

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run desktop:web
```

打开终端中的本地地址，也可使用原 Web 入口 `npm run dev`。

```bash
npm run check
npx tsc --noEmit
```

`check` 包含自动测试、lint、Web 构建与桌面前端构建。`npm run desktop:dev` / `npm run desktop:bundle` 另外需要 Rust/Cargo 与 Tauri Windows 系统依赖；前端构建通过不代表安装包通过验收。

## 游玩

- 逐句阅读下方对话框，读完后选择行动。立绘随说话人切换，旁白也逐句推进。
- 完成或错过序章后接续江湖。长篇有 19 个关键事件，第 58—60 日处理终局。事件有期限，旅行、工作与休息都会耗时。
- 从“眼前、谋生、修习、旧事”选择行动。侠行、行商、暗行、从官、行医由行为积累，可交叉发展。证据、钱财、追查和 NPC 关系决定机会。
- 修习提高能力，立约有收益与义务，改行或解约有代价；债务和追查均有处理途径。
- 第 58 日起，满足条件的方向可进入各自终局，也可能提前远走、退隐、被拘或死亡。

## 系统与存档

保留五维 NPC 关系、事件记忆、主张与事实分离、认知地图、经济事务与旧债、伤病与疲劳、能力与技能树、历史、自动存档及最多 20 个手动档。人物姓名和身份仍须确认，未知往事通过传闻得知，结局按实际发生的事实叙述。

结构版本 v6，继续使用 `qingshi-jianghu-save-v5` 存储键，兼容原有合法 v5/v6 档。缺少长篇字段的旧档补初始状态，损坏或矛盾状态拒绝读取，不支持 v1—v4。浏览器使用 localStorage，Tauri 保留 SQLite 仓库。读档恢复快照时刻；读取、渲染和进出场景本身不会重放事件或倒拨档内时间。

九张原创水墨风 SVG 半身立绘位于 `public/portraits/`，绑定集中在 `lib/game/portraits.ts`。长篇内容、规则和存档分别在 `campaign-content.ts`、`campaign.ts`、`campaign-storage.ts`。外县行程以耗时剧情往返表现，不提供无限期沙盒或新增外县大地图。

## P0 / P1 本地技术交付

立绘和八幅场景均支持根路径与 Pages 项目子路径，并提供文字降级。Pages地图在项目目录内使用片段导航；本地 `npm run desktop:web` 的首页可直接打开。背包入口支持已知来源、用途与原选项确认，旧档中的英文材料名仅在显示时转换。

十九事件与特殊转折已登记在唯一详细分支图，三账各有三个独立场景来源的实际取证测试。规则与存储版本不变，没有新增亲密度或人物规模扩写。本轮未提交、推送、发布；技术结果和稍后真人试玩的边界见实施与验收总记录。
