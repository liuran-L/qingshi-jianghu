# 青石江湖

离线、低魔的单机文字武侠。“雨夜盐引”序章接续到第六十日的人生终局。所有选择、经济、关系、成长与冲突由本地规则裁决，表达层使用 mock，无真实模型、API Key 或联网游戏功能。

## 启动与验证

要求 Node.js 22.13 或更高版本。

```bash
npm install
npm run desktop:web
```

打开终端中的本地地址，也可使用原 Web 入口 `npm run dev`。

```bash
npm run check
npx tsc --noEmit
```

check 包含自动测试、lint、Web 构建与桌面前端构建。`npm run desktop:dev` / `npm run desktop:bundle` 另外需要 Rust/Cargo 与 Tauri Windows 系统依赖；前端构建通过不代表安装包通过验收。

## 游玩

- 逐句阅读下方对话框，读完后选择行动。立绘随说话人切换，旁白也逐句推进。
- 完成或错过序章后接续江湖。长篇有 19 个关键事件，第 58–60 日处理终局。事件有期限，旅行、工作与休息都会耗时。
- 从“眼前、谋生、修习、旧事”选择行动。侠行、行商、暗行、从官、行医由行为积累，可交叉发展。证据、钱财、追查和 NPC 关系决定机会。
- 修习提高能力，原步法与医术技能树仍可继续学习。立约有收益与义务，改行或解约有代价；债务和追查均有处理途径。
- 第 58 日起，满足条件的方向可进入各自终局。同一路线也有公开、妥协、护送、经营或远行等不同处置，也可能提前远走、退隐、被拘或死亡。

## 系统与存档

保留五维 NPC 关系、事件记忆、主张与事实分离、认知地图、经济事务与旧债、伤病与疲劳、能力与技能树、历史、自动存档及最多 20 个手动档。人物姓名和身份仍须确认，未知往事通过传闻得知，结局按实际发生的事实叙述。

结构版本 v6，继续使用 `qingshi-jianghu-save-v5` 存储键，兼容原有合法 v5/v6 档。缺少长篇字段的旧档补初始状态，损坏或矛盾状态拒绝读取，不支持 v1–v4。浏览器使用 localStorage，Tauri 保留 SQLite 仓库。清理站点数据会删除浏览器存档。读档恢复快照时刻；读取、渲染和进出场景本身不会重放事件或倒拨档内时间。

## 内容与资源

九张原创水墨风 SVG 半身立绘位于 public/portraits/，绑定集中在 lib/game/portraits.ts，可替换正式美术。长篇内容、规则和存档分别在 campaign-content.ts、campaign.ts、campaign-storage.ts。

当前是六十日关键事件加日常行动，外县行程用耗时剧情往返表现，没有无限期沙盒或新增外县大地图。设计取舍、十条通关测试路径、验证边界与参考资料见 [六十日完整篇实施与验收](文档/青石江湖-六十日完整篇实施与验收.md)。旧阶段报告保留为历史记录。

## 2026-09-06：主界面、行程笺与成长战斗扩展

启动先显示“新的旅程 / 继续旅程”。新旅程进入命名，继续旅程打开有日期、剧情日数、地点、人物状态和结局状态的存档列表。游戏顶部固定“返回游戏主界面”，一次确认后不保存、清理内存，已有档不删除。

新旅程遇到已有自动档时保护旧档，本旅程使用手动存档；从自动档继续或自动档为空时，正式行动与地图旅行仍生成自动检查点。命名、读档、翻页、打开地图和返回主界面本身不写自动档。地图用独立内存快照往返，不以覆盖旧自动档作为导航前提。

对话支持慢、标准、快、关闭四档逐字显示，默认标准。点击对话或聚焦后按 Enter/空格先补全，再推进；“跳过本段显示”立即显示本段末句。历史、日志、选项、存档摘要始终静态完整。速度为本机阅读偏好，不混入规则存档。

行程笺展示公开消息窗口、失效时刻、五条路线的成长与去向缺口。统一功法页整合实践、阅历、属性研习、师承、立约、点数与前置。四树共 14 个节点，每个节点在两个具体剧情现场开放实际回响，共 28 处。首点可免费接受实际指点；实践兑换每次四小时、三两、两点对应阅历。全篇技能点上限七点，专精并兼修可实际获得五至七点；不要求不练功的玩家也拿满。

七处剧情冲突接入确定性裁决：廊门伏击、护送过闸、码头断索、医馆追捕、药船争渡、护证夜路、盐仓破阵。进攻、守势、环境、撤退、交易、质证与投降按条件开放；原三账、护送等剧情解法保留。助阵取决于存活、在场或约定、信任、敌意和战斗等级，失败可以失证、负伤、增加追查、同伴负伤、被拘或死亡。

GameState 仍为 v6，新增 arts / battles 两个 schema 1 账本。合法旧档补空账本，新状态必须通过来源、点数、前置、时间和结果交叉校验；坏自动档仍可走原备份回退。

本轮验收详见 [主界面成长与战斗扩展验收报告](文档/青石江湖-主界面成长与战斗扩展验收报告.md)。未进行真实浏览器点击或原生安装包实机测试。


## 2026-09-06：功法图与已知情报交互

“成长”统一页现名“功法”，保留全部实践、阅历、研习和立约入口。四棵树的 14 个节点以真实前置连线展示，支持键盘聚焦详情和窄屏滚动；未解锁、可学习、已学习与受条件限制同时使用文字、图标和不同边框标识。只有当前规则与阅读状态都允许，才可从详情投入点数。

已知情报按线索、已知事实、随身物、地点、人物、世界事件分类，默认仅显示名称，点击展开或收起。读档、切换场景、已知信息变化会清除展开状态。返回主界面弹窗仅有“取消”“确定”，正文提示未保存进度丢失，确定不保存且不删除已有存档。

本轮仅修改呈现，存档仍为 v6，无新增存档字段。详见 [功法与情报界面设计及验收](文档/青石江湖-功法与情报界面设计及验收.md)。
