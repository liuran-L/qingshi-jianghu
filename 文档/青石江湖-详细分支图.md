# 青石江湖详细分支图

更新：2026-09-08。本文是唯一的场景级分支与内部设计过滤器验收文档。它替代早期第一、二日历史分支图；所有新场景和回补场景均在此登记后才可实现。

## 使用方式

每个重要场景必须登记：默认世界结果、玩家介入路径、拒绝或缺席路径、即时可感反馈、长期回声、信息替代来源、状态写入和测试用例。沉默不等于每场必有按钮；仅在盘问、承诺、施压或关键介入点出现，并在同轮只保留一个语义明确的选项。

## 状态与表现规则

- 世界事实写入事件结果；玩家已知仅由目击、传闻、证物或合理交谈取得；主张、谎言、承诺和矛盾写入独立记录。
- 跨场景回响只记录必要的拒绝、承诺、矛盾口供、错失机会和证物归属；不为轻微沉默建立泛滥计数器。
- 关系详情只显示由既有五维状态投影出的阶段，不显示具体分数；只有阶段实际变化才显示简短非数值提示。戒心、话题关闭、NPC 改口和机会消失以角色与环境反馈表现。
- 失败除明确终局外必须保留替代路线。旧话题可在新证据、关系变化、NPC 主动再提或时间推进后以新情境重开，而非重复原按钮。

## P1 与 P2 验收

P1 完成时，十九个关键事件、城门、客栈、医馆、证物与关系转折及三类终局都必须填入模板并通过设计审查。P2 按场景组实现并测试：缺席结果、沉默或拒绝的收益与代价、NPC 回声、替代路径、存读档、旧档默认值和非终局失败续路。任何未满足模板的场景不得标记完成。

## P0 开发前准入清单（2026-09-08）

### 节点与玩家牵引

- 城门首次盘查：删除无条件要求放行和沉默通行；保留如实或有限说明、已有观察/物件、按无路引规矩候验、明确银钱交换及退开复核。任何放行都须能追溯到口供、凭据、关系或实际支付。
- 第一日三条入口：行囊外部被人识别的痕迹；守门差役听见“丁字十七”后的异常反应；客栈中有人提前打听负伤外乡客及其行囊。三者各自独立，不把任何一条写成幕后定论。
- 日末回补：跨入第二日时，若三条主动入口均未取得，则通过换更人口中的打听者与码头去向提供较弱保底；无论是否主动调查，都留下“次日人、船或现场会变化”的可见压力，但不设置立即失败。
- 场景去向：只在对话收束或当前地点没有有效探索时展示，按伤势、现场窗口、船车变化排序，至多列出两条叙事去向；普通闲聊和仍有可查内容时不显示。
- 姓名连续性：基础对话、首日回声、序章、十九事件及终局文本统一经过玩家视角称呼投影；拒绝姓名后继续使用外貌/身份称谓。事件中只有自报、名帖、簿册点名或在场者明确称呼后，才同步人物资料与后续称呼。

### 状态字段与存档迁移

- `GameState.version` 保持 6，存储键保持 `qingshi-jianghu-save-v5`。
- 第一幕新增信息只写入 `playerKnownFactIds`，使用世界表登记的合法 ID；旧 v5/v6 缺少这些 ID 即表示尚未知，不反向补发。
- 城门沿用 `gatePhase`、`gateAccess`、`playerClaims`、`npcStates.memory`、`player.money` 与现有证物归属；不新增沉默次数、放行捷径或重复支付账本。
- 关系阶段与场景去向均为显示投影，不写入存档；读档、渲染、人物切换和地图往返不会推进时间、重演事件或再次弹出阶段变化。
- 姓名仍写入 `npcKnowledge`；本轮只修正明确取得时点和显示投影，不从旧档的世界事件、私有定义或未知对话猜测姓名。

### 设计过滤器审查

- 三条首日入口只共同支持“有人关注主角并盯着其行囊/所携之物”，不指认马三刀、苏晚棠、乔五或任何其他人为幕后主使。
- 日末线索来自沿街换更、客栈与码头之间可观察的行为，强度低于亲见；玩家缺席不停止船、人和痕迹变化。
- 去向文案说“去哪里做什么”，不出现任务、正确路线、推荐答案或隐藏数值；最多两个方向，紧迫项优先。
- 关系变化未跨阶段时不显示系统提示；拒绝、轻微信任、戒心与敌意继续由台词、服务边界和后续行动表达。
- 十九事件不新增分支、关键人物、结局或世界观；只修正称呼投影、明确姓名来源和既有前提的连续性。

### 自动化与真人试玩边界

- 自动化新增：首次城门无沉默/无条件放行；四类现实依据及代价；姓名拒绝、自报、事件点名和历史投影同步；关系阶段显示与仅跨阶段提示；三条独立首日入口、日末保底和次日可变线索；v5/v6 缺省不补姓名/线索且读档不重复；十九事件及序章/终局称呼不越权。
- 回归继续覆盖：十九事件缺席与三账来源、证物归属、关系去重、死亡/拘押/终局冻结、浏览器与 Tauri 存档、网页与桌面前端构建。
- 真人试玩仍须由三名符合画像的真实玩家各自无讲解游玩 30—60 分钟；自动化和开发者自测不能替代，也不得在未执行前标记通过。

### P0 实施回写

- 已落地四个玩家已知事实：行囊辨认痕迹、客栈提前问话、错过主动调查的日末传闻、命中入口后的次日变化归纳。只在时间写入口结算一次；死亡后、长篇已经开始或纯读档时不补发。
- 城门新增可核验文书与主动出示残片两种动作，调整按规候验与两两私下通融；首次沉默、无依据放行不再生成。残片被暂扣后仍走原复核、归还和证物归属链。
- 所有十九事件保留原分支、人物、结局和世界观，只在首次遇到事件说话者时增加可追溯姓名来源并同步 `npcKnowledge`；玩家可见文本按当前知情状态遮蔽未知全名。
- 场景引导与关系阶段都是纯显示投影；关系跨阶段提示仅由一次已确认行动的前后快照比较生成，读取旧档不会弹出。
- 自动化用例 `P0-01` 至 `P0-06` 覆盖上述规则；真人试玩仍是唯一未完成的 P0 验收项。
## P1 逐场景准入登记

内部审查不进入玩家界面。三条独立路径对应全篇官印、运输、药库三类核心证明；序章尸体实名是可选封存分支的局部核验，不是全篇必经门槛。P1复用既有事件，不新增人物探索或亲密度。

### temple · 破庙一灯

- 固定行动与缺席结果：旧香客说庙里有人负伤住过，后来只剩一滩干血。遗嘱的另一份抄件被送向北山。窗口在第5日09:00截止，不等待玩家。
- 介入目标与即时反馈：shelter：“别把命许得太轻。”你替他换了干草，又在岔口留下向西的脚印。天亮时他把遗嘱交给你，信物仍握在自己手里。；medicine：沈砚秋在灯下拆开旧绷带：“能稳住，不能还你年轻时的身子。”岳寒声让你抄下药库签押，算作诊资以外的人情。；copy：你把能做与不能做的说清。老者点头，让你抄一份遗嘱带给陆观澜；他仍留在庙里，没人替他挡追兵。；steal：纸薄得几乎没有声音。你带走了纸，却没带走他肩上的伤；醒来后他只会记得，托付没有等到答复。
- 拒绝、观望、收益与代价：不承诺护送，只送信或暂离；保留自由但不护住老人。
- 长期回声与重开：遗嘱可用于公议，陆观澜仅承认实际托付。原事件不重开；缺席结果从行旅消息取得，替代来源在后续窗口出现。
- 世界事实 / 玩家已知 / 玩家主张：resolved保存结果；witnessed只在目击或打听后为真；不为缺席补写立场、承诺。NPC边界：岳寒声知道门内药源，不知道官档。

- 状态与迁移：campaign.resolved / journal / flags / evidence / npcAlive与npcStates.memory.appliedEvents；无新增字段，原事件键和关系记忆防重复，旧档不补选择。
