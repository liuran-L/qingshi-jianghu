# 《青石江湖》世界观与剧情设计

> 版本：阶段一剧情底稿 1.1  
> 最近更新：2026-09-04  
> 范围：完整八日事件骨架；开场至第二日为当前优先可玩内容。

## 一、创作原则

《青石江湖》不是一条等待玩家完成的固定主线，而是一套会自行运转的县城危局。

- 大事件按照世界时间发生，不等待玩家接取任务。
- 玩家可以调查、交易、撒谎、站队、旁观或离开。
- 玩家说出口的话属于“主张”，不会自动改写世界事实。
- NPC 只根据自身经历、立场与已经掌握的证据作答。
- 同一条线索在不同知识背景下会产生不同解释。
- 重要信息至少设置三条获取路径，避免一名 NPC 死亡、拒绝合作或玩家错过现场就让剧情断裂。
- 玩家可以改变事件结果，但不能让整个世界为自己暂停。

## 二、世界基调

故事发生在大雍南部。十三年前，朝廷与主要江湖门派签订“止戈盟约”：登记门派不得公开割据，官府也不随意围剿守约门派。

这是一套低魔武侠世界：内功、点穴、奇毒和秘药真实存在，但不能让人脱离血肉之躯。高手仍会受伤、中毒和死亡。身份、路引、证据、人情与名声，往往比单纯武力更能决定一个人的处境。

青石县位于青石河与北山古道的交汇处。官盐由此转运南下；漕帮控制水路与脚夫；青岳门控制北山通道；县衙维持表面秩序，内部却已被利益渗透。

## 三、贯穿全局的核心秘密

官府档案中只存在一批“丁字十七号”官盐，但实际出现了两张几乎相同的盐引。

有人利用伪造盐引，在合法官盐的掩护下运输私盐与乌鳞散原料。县衙内鬼负责伪造印信，漕帮负责水路运输，青岳门现任大师兄暗中出售门派禁地中的原料。

三方并非忠诚同盟：

- 县衙内鬼准备在事败后把罪名全部推给漕帮。
- 青岳门大师兄准备销毁运输链，掩盖自己毒害掌门、争夺继承权的事实。
- 乔五察觉自己可能被灭口，准备扣下货物和账本反制另外两方。
- 三者彼此利用，也都准备在最后时刻背叛另外两方。

这使剧情不会收束为“击败唯一幕后黑手”。即使其中一人提前死亡，另外两方仍会继续行动。

## 四、核心线索：丁字十七号残缺盐引

盐引残片具有四层含义：

1. **纸面信息**：能够辨认出“丁字十七”与残缺县衙火漆。
2. **黑鳞蜡痕**：漕帮内部用于标记特殊货物的记号。
3. **苦涩药味**：来自乌鳞散原料，需医术或医者帮助才能确认。
4. **伪造印信**：需熟悉衙门文书的人与真盐引比对后才能确认。

不同人物的知识边界：

| 人物 | 能确认的内容 | 不知道的内容 |
|---|---|---|
| 马三刀 | 黑鳞货车可以免检；乔五常走东侧小门 | 盐引用途、乌鳞散与刺杀计划 |
| 苏晚棠 | 私运抄账中有“丁十七” | 假盐引由谁制作 |
| 顾清河 | 官盐账目长期亏空；县衙有人泄密 | 漕帮账本和刺客身份 |
| 宁不平 | 马三刀手脚不净；县令在查盐 | 青岳门遗嘱和刺杀日期 |
| 乔五 | 假盐引用于特殊货物；县衙有人接应 | 青岳门大师兄准备灭口 |
| 沈砚秋 | 黑色残留物与乌鳞散有关 | 谁在运输、谁伪造盐引 |
| 岳寒声 | 原料来自青岳门禁地；掌门之毒来自门内 | 县衙掌握了多少证据 |
| 陆观澜 | 师兄佩剑在码头出现；岳寒声秘密离山 | 自己的身世与完整运输链 |

## 五、开场事件

主角原本随一支商旅队伍经过青石县附近。暮雨中，队伍在县城三里外遭到袭击。

袭击者的目标不是主角，而是队伍中一名发现假盐引的账房先生。账房将盐引残片塞进主角破损的行囊，随后在混乱中失踪。主角被淬有少量乌鳞散的兵刃划伤，路引与部分财物也被夺走。

主角醒来时只掌握以下信息：

- 同行者已经失散。
- 身上有一道持续渗血的轻伤。
- 路引遗失，行囊被翻乱。
- 昏沉中曾听见袭击者喊“找丁字十七”。
- 天色将晚，附近唯一能及时抵达的安全地点是青石县。

盐引残片不会自动出现在玩家情报栏。玩家检查行囊后才能发现；检查伤口可以发现伤势异常；回忆袭击则能巩固“丁字十七”这一语句线索。

## 六、主角初始状态与需求

- 气血：78/100。
- 伤势：轻伤。若长时间不处理，气血会继续下降。
- 疲劳：65/100。赶路和长时间行动会增加疲劳。
- 路引：遗失。
- 碎银：保留少量藏在贴身处的银钱。
- 身份：主角知道自己的姓名与基本出身；不了解青石县和当地人物。

住宿与求医不是任务提示，而是系统需求：

- 客栈能够安全休息、恢复疲劳，但需要银钱并留下住宿记录。
- 医馆能够处理伤势并识别异常毒物，但可能要求说明受伤经过。
- 玩家也可以自行包扎、冒险露宿或寻找其他帮助，并承担相应代价。

经济压力只承担“迫使玩家取舍”的作用，不把游戏变成生计模拟。标准开局银钱应够支付一次普通治疗与两至三晚普通住宿；银钱不足时仍可选择欠诊金、一次性杂活、简陋处理或较危险的落脚方式。

## 七、八日固定事件时间轴

| 故事日 | 必然发生的事件 | 可被改变的结果 |
|---|---|---|
| 第一日 | 商旅遇袭；主角抵达城门 | 是否发现盐引、如何解释身份、是否暴露伤势 |
| 第二日 | 河边发现一具带有相似伤口的无名尸体 | 尸体由谁检查、证物是否被取走、消息如何传播 |
| 第三日 | 丁字十七号货船抵达漕帮码头 | 货物被转移、扣押、焚毁或劫走 |
| 第四日 | 岳寒声负伤藏入城外破庙 | 遗嘱和信物落入不同势力之手 |
| 第五日 | 县令顾清河遭遇刺杀 | 死亡、中毒、获救、假死或误判凶手 |
| 第六日 | 青岳门宣布掌门去世 | 继承人身份是否公开，门派是否分裂 |
| 第七日 | 漕帮焚烧码头账房灭证 | 抄账、证人和货物是否保存 |
| 第八日 | 县衙封城，各方开始清算 | 谁控制城门、谁被通缉、哪一方掌握证据 |

事件只表示“行动发生”，不规定唯一结果。例如第五日刺杀必然发动，但县令不一定死亡。

## 八、第一日至第二日的可玩路径

两日内容不要求八名核心 NPC 全部登场。马三刀、苏晚棠、陆观澜和沈砚秋构成主要体验；宁不平、顾清河和乔五只在玩家主动报案、被拘押、追踪或交易时提前出现。岳寒声第四日才藏入破庙，第一、二日不能通过猜测姓名或地点找到他。

第一日的软目标是解决“如何进城、如何处理伤口、在哪里过夜”；第二日的软目标是决定“是否把无名尸与自己的危险联系起来”。软目标不等于任务，玩家可以拒绝调查或尝试离城。

### 8.1 城门盘查：马三刀

马三刀先索要路引，再根据衣着、口音、伤势与现场同僚盘问姓名、籍贯、来由和落脚处。他记录玩家的说法，而不是只判断一次口才成败。

- 玩家可如实说明、只说部分事实、声称记忆混乱、报假名、沉默或反问规矩。
- 玩家询问住宿，才可能得知悦来客栈；说明伤势或求医，才可能得知回春堂。
- 提到“丁字十七”时，他表面否认，动作和盘问强度却可能发生变化，并可能暗中向乔五递话。
- 公开行贿会让他顾忌同僚；顶撞或威胁更可能导致刁难、搜查、扣押或叫来同僚，而非无理由杀人。
- 戒心与证据达到不同阈值时，结果可为放行、留档放行、搜查或拘押复核；拘押是独立可玩路线，不是强制读档。

### 8.2 场景调查：行囊、伤口与货车

- 检查行囊可发现盐引残片。低洞察只能看出旧公文和编号，后续知识会逐层更新解释。
- 检查伤口只能观察到持续渗血与边缘发暗；医术不足时不能直接得知乌鳞散。
- 留意城门免检货车可留下车夫、车辙或黑鳞标记的观察记忆，为第二日辨认和跟踪提供条件。
- 未发现残片也是有效状态：残片仍留在夹层，之后可能被搜查者、店伙或其他势力先发现。

### 8.3 悦来客栈：苏晚棠与陆观澜

苏晚棠围绕房钱、住客登记和实际风险交谈，不会无条件介绍自己的经历。玩家可以报真名、假名或拒绝登记；记录会在第二日与城门口供发生比对。若玩家请求便宜房间或以工抵宿，只提供有限且有时间成本的方案。

玩家追问她的姓名或私事遭拒后，无新依据时话题关闭；继续施压只会提高戒心。若玩家曾帮忙、守诺或表现出分寸，她可能在第二日对跟踪风险作含蓄提醒。

陆观澜以反问、玩笑和半真半假的试探判断玩家。他可以谈商旅、货车或身法，却不会主动交代门派秘密。第一日的基础点评可在第二日开启一次短暂切磋或步法练习，只留下成长记录，不直接授予高阶功法。

### 8.4 回春堂：沈砚秋

沈砚秋先问伤口形成时间、兵刃和处理经过。玩家可如实回答、撒谎、拒绝或反问诊金，并分别影响诊断精度和信任。

- 只有获得玩家同意并实际检查后，他才保存主角伤口的观察证据。
- 玩家可付钱治疗、欠下人情、做一次药房杂活抵部分诊金，或只接受基础止血。
- 第二日无名尸送来后，只有已经检查过主角伤口，才能进行“两处伤口比对”；否则只能介绍尸体本身可见情况，或重新检查主角。
- 基础包扎、辨伤与用药建议可成为医术成长种子，但重复问诊不能刷熟练度。

### 8.5 第二日：无名尸及跨日回声

尸体在河边被发现后送往回春堂。事件先写入隐藏世界状态；玩家只有通过河边目击、客栈传闻、医馆接触、县衙询问等合理渠道才会得知。

第二日必须读取第一日留下的事实：

| 第一日行为 | 第二日可能回声 |
|---|---|
| 公开提过“丁字十七” | 更易被跟踪，马三刀的盘问更具体 |
| 客栈报真名或假名 | 住客记录可与城门口供相符或冲突 |
| 允许沈砚秋检查伤口 | 可出现两处伤口的证据比对 |
| 拒绝检查 | 不能直接得出同源结论，只能补做检查或另寻证据 |
| 观察免检货车 | 可辨认第二日出现的车夫、车辙或货物标记 |
| 帮助苏晚棠或保持分寸 | 她可能含蓄警告跟踪或记录风险 |
| 激怒马三刀或口供矛盾 | 再过城门时遭额外复核，或由宁不平接手 |
| 搜查中暴露残片 | 第二日从县衙拘押与复核口供开始 |

玩家得知尸体后可调查、协助、举报、藏证、取走证物、向乔五交易，或完全不理会。第二日允许形成治伤获信、隐瞒追查、假名低调、县衙交证、漕帮交易、拘押复核等不同状态，不设置唯一正确答案。

## 九、NPC 对话、关系与记忆规则

关系不使用一个公开的“好感度”概括，而由态度、信任、戒心、敌意和人情分别记录。玩家只能从语气、称呼、动作、价格和服务意愿判断关系；高洞察可让判断更准确，但不能直接读取秘密。

NPC 要记住具体发生过的事：玩家报过什么身份、展示过什么证据、说法是否矛盾、是否守诺、欠债、帮助、背叛、某话题被询问或拒绝多少次，以及谈话因何结束。不同人物的交谈结构也应不同：马三刀盘问，苏晚棠交易，沈砚秋诊断，陆观澜试探。

有限模式中，遭明确拒绝的话题应移除重复按钮。获得新证据、关系变化、时间推进或场景改变后才可重新开启。未来自由输入模式仍允许玩家执意追问，但会产生戒心、反感、涨价、假话、拒绝服务或结束谈话等规则后果。NPC 也可以主动提问，谈话会因公务、疲劳、戒心、时限或现场变化自然结束。

对话之间可插入短小场景事件，例如城门换岗、客栈伙计送错口信、医馆忽然收治伤者或免检货车经过。它们不承担强制发任务的职责，而是让 NPC 暂停、改口、离开或产生新的观察机会，使县城显得在自行运转。

## 十、轻经济与成长方向

- 银钱主要拓宽便利选项，例如购买更好的药、情报、训练或风险转移，不把基本生存变成长期硬门槛。
- 可选收入来自有限杂活、护送、出售情报、协助医馆或势力委托；每项有时间、次数和风险限制，不可靠重复对话无限刷取。
- 成长由武学、轻功、洞察、口才、警觉、医术的实际使用，以及训练、请教、师承、秘籍和时间共同推动。
- 功法可分为招式、套路、内功、轻功和特殊技艺；取得秘籍只获得学习条件，不能立即精通。
- 第一、二日以建立能力基线和埋下师承机会为主；第 3—8 日才适合获得第一项基础技艺或招式，之后在六十日中逐步形成方向与专精。

## 十一、自由选择与失败状态

玩家可以把线索交给、卖给或隐藏于任何势力，也可以撒谎声称自己具有某种身份。系统记录的是“玩家的主张”与“NPC是否相信”，而非直接修改真实背景。不调查、沉默和离开都是有效选择，世界会继续结算。

过早公开“丁字十七”可能导致跟踪、搜查、绑架或灭口；冒充官差可能引起拘捕；向不同势力提供冲突说法会形成长期矛盾记录。失败不应只返回“没有获得信息”，还可以转入谎言暴露、欠债治疗、拘押复核、反跟踪或被迫交易等新路线。

死亡可以发生，但应来自能够理解的风险累积：伤势恶化、极度疲劳、危险言论、战斗失败或遭到有准备的势力报复，而不是随机惩罚。

## 十二、阶段实施边界

当前代码已具备的基础包括：

- 开场受袭状态；
- 伤势、疲劳与路引状态；
- 检查行囊、伤口和袭击记忆；
- 丁字十七残片与分层线索；
- 住宿休息与医馆治疗；
- 第二日无名尸体事件；
- 八日事件定义、时间触发和存档字段。

本次补充的第一、二日扩展对话、五维关系、具体事件记忆、重复话题锁定、跨日回声、轻经济兜底和早期成长节奏属于下一阶段开发基线，不能视为已经全部实装。具体分支以[第一、二日扩展对话流程分支图](./青石江湖-第一二日扩展对话流程分支图.md)为配套设计。

第三日至第八日暂以事件骨架为主。后续扩写必须继续遵守 NPC 知识边界，不能让一个人物为推进剧情而突然知道全部真相；关键线索应保持至少三条可替代获取路径。
