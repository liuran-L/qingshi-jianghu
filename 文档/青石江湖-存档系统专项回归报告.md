## 操作分支覆盖图

```text
新开局／规则推进
  └─ 自动保存 → 成功／写入失败→保留旧档→重试
存档管理
  ├─ 新建 → 空位→命名／默认名／取消
  │         满20档→拒绝→覆盖／删除／取消
  ├─ 覆盖 → 确认→写入／失败保留旧档；取消→不写入
  ├─ 改名 → 新名／空白拒绝／取消／写入失败
  └─ 删除 → 确认→移除／失败不移除；取消→不写入
读取
  ├─ 有效档 → 当前已保存→恢复
  │           当前未保存→先保存／不保存读取／取消
  ├─ 自动档坏或缺失 → 有效备份→确认恢复／取消
  │                    备份也坏→拒绝读取
  └─ 手动档坏 → 不加载、仍占位→确认覆盖／删除
恢复后 → 真实规则交互→自动保存／另存／再次读取
```

## 问题记录与根因

| 类型 | 原问题 | 修复与验证 |
| --- | --- | --- |
| 逻辑缺陷 | 内容和名称时间分两次写入，后一次失败造成部分成功 | 单记录保存内容与元数据；S10、S11验证失败不替换主档 |
| 逻辑缺陷 | 重复保存同一进度挤掉有用备份；备份预览借用主档时间 | 保留上一个不同的有效状态与自己的时间；S02验证 |
| 预期不符 | 坏手动档消失并被当成空槽 | 分离可读取状态与占用状态，坏档可见且占位；S09验证 |
| 逻辑缺陷 | 先保存再读自动档可能读到刚保存的当前状态 | 先读取目标快照再执行保存选择；S07验证 |
| 逻辑缺陷 | 异步读写无顺序约束，新进度可能被旧请求盖掉 | 仓库队列、提交快照、失败后队列恢复；S15验证 |
| 逻辑缺陷 | 快速重复新建可能争用同一空位 | 完整新建流程排队，页面操作加互斥；S18验证 |
| 逻辑缺陷 | 存档只粗略校验嵌套对象，非法NPC字段可能在继续游玩时报错 | 加强结构、范围、地点、死亡状态、事件引用检查；S13、S20验证 |
| 预期不符 | Tauri损坏主档不回退、单个坏JSON可使整个列表失败 | 仓库统一校验、显式备份读取、Rust列表容错；S17为桥接契约验证，原生执行限制见下 |
| 逻辑缺陷 | Rust槽位解析接受manual-01等别名，突破规范槽位集合 | 改为auto及manual-1至manual-20精确匹配；TS边界S13通过，Rust未编译实测 |
| 体验/逻辑缺陷 | 初始化、手动操作和地图存档失败可能没有提示；地图返回回到开场 | 接入统一错误处理、操作互斥及地图场景交接；S16验证交接模块，页面编译检查通过 |

迭代中还修正了一个测试自身的预期：现有 advanceGameTime(0) 至少推进一分钟。测试改用正数步长，未修改游戏时间规则。
