# 功法与情报界面设计及验收

日期：2026-09-06。本轮范围仅为界面呈现与交互，未修改剧情、人生路线、成长裁决、已知情报定义、存档编解码或关系数据。

## 实现与取舍

1. 统一页面更名“功法”，保留实践、阅历、属性研习、立约与原有训练入口。四树 14 节点按既有层级绘制，前置线来自节点定义。现有规则没有汇合前置，因此没有为图形增加虚构汇合。叶节点注明分支终点。
2. 图示状态分未解锁、可学习、已学习、受条件限制。文字与图标、虚线/实线/双边框/加粗侧边、明暗和连线共同表达。已学前置对应实线，其余前置线为虚线。HTML 按钮承载交互，SVG 仅绘制技术连线，不引入外部美术。
3. 节点显示名称、点数成本、前置与短效果；点击或 Tab 聚焦展开完整详情。详情呈现入门、兑换、原有基础研习的不同成本和当前阻断，沿用定义中的规则效果与剧情回响。投入按钮只在实际可用动作存在、规则前置满足、当前对话完成且没有结算忙碌时出现，仍调用原有行动结算。
4. 图保持固定节点间距并横向滚动；滚动区可获得焦点并使用方向键，节点可 Tab、Enter/空格操作。每个节点提供展开状态与详情区域关联，视觉前置关系另有文字等价说明。无拖拽、缩放。
5. 已知情报六分类使用原生 select，条目按钮仅显示名称，按需展开且再次点击收起。名称短标题属于 UI 投影，不改事实正文。随身物包含当前持有的长篇证据；地点仅提示已知或当前所在，避免远程描述冒充实时观察。人物只展示已观察外貌和已确认姓名身份，世界事件只展示已知标题与已知状态提示，不读取隐藏摘要、NPC 私有知识或未获知的事件结果。
6. 展开状态为组件内存；分类变化收起详情。投影内容、地点、交谈对象、剧情场景或终局场景改变会重建情报组件，同一存档再次读取也用纯 UI 修订号清除展开。新建旅程、返回主界面卸载组件，不保留详情。
7. 返回弹窗保留原正文“未保存的进度将会丢失”，按钮仅“取消”“确定”。取消关闭弹窗；确定复用原会话清理，丢弃内存，不保存、不删除已有档。原有存储与地图会话回归继续覆盖数据保护。
