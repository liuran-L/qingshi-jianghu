## Bug、根因与修复

| 类型 | 问题与根因 | 修复 |
|---|---|---|
| 逻辑缺陷 | 问路选项被gateAccess=false包住，先放行则永久消失 | 放行后仍可问尚未知的住宿/求医地点 |
| 剧情偏离 | 问出马三刀姓名就从盘问切到放行选择，实际并未说明来由 | 自报姓名后继续questioning，移除重复问名但保留回答盘问 |
| 逻辑缺陷 | 客栈话语提到回春堂，规则没有发现地点 | 传闻事务同步记录clinic地点 |
| 逻辑缺陷 | 搜查旁白夺走残片，事务只设置拘押没有物品移除 | 增加规则事务移除物品字段，保留已知线索；未引入新存档结构 |
| 剧情偏离 | 扣留台词说已去班房，但location仍是城门 | 明确为城门侧看押、等班房来人，不虚构完成转移 |
| 逻辑缺陷 | getLimitedActions只按knownName决定姓名按钮，拒绝永远可重问 | 以现有learnedFacts保存可知的拒答记录，有限模式移除按钮；未增加完整关系系统 |
| 逻辑缺陷 | advanceGameTime先判死，随后healthDelta又把气血加正 | 死亡为终止状态；不发完成收益，时间不越过死亡时刻 |
| 逻辑缺陷 | movePlayer无视途中死亡，继续设地点、NPC并写抵达 | 死亡时保留出发地，保留死亡日志，不写成功抵达 |
| 逻辑缺陷 | 低气血检查未判断是否仍有伤，已治伤者再次变重伤 | 只有已有伤势才进行恶化判定 |
| 剧情偏离 | 每次进入医馆都重演同一担架；停在医馆跨阈值却只有新按钮无现场 | 单次现场观察，在时间和移动结算中统一触发，保留其旁白/日志 |
| 剧情偏离 | 尸体问答自动确认沈砚秋；治疗也没有自报姓名依据 | 尸体问答不确认姓名；治疗答话补足明确自报；比对引用“先前”而非固定“昨日” |
| 剧情偏离 | 未问姓名时日志和情报暴露马三刀及递话目的 | 改成可见差役动作，不公开隐藏收信方；隐藏递话标记仍由规则保存 |
| 剧情偏离 | 已有一轮对话就被当作私下行贿场景 | 无真实私下场景时固定公开拒收，不提供虚假私下情报 |
| 剧情偏离 | 零钱治疗Mock说已包扎，但状态没处理；住宿总说天亮 | 如实说未治疗；住宿描述六个时辰，不捏造昼夜变化；未增加免费治疗 |
| 逻辑缺陷 | 页面只靠React忙碌状态防重，异步期间还能切NPC造成回写错位 | 提取共用点击函数、同步互斥、阅读位置与目标检查；页面接入并禁用冲突操作 |
| 逻辑缺陷 | 只检查actionId，不校验请求模式；空目标可伪装说话 | 同时校验模式与NPC所在地点/目标；禁止越权事务 |

## 仍缺失的分支与阶段边界

1. 城门：失忆/籍贯细分、货车追问、主动搜查、暂退旁观、真正私下通融、第二日口供复核。早期观察城门的图示入口与当前递进时机也不完全一致。
2. 客栈：同行者调查、残片试探、独立登记选择、假名与拒绝登记、便宜房/抵宿工作、第二日称呼/信任/跟踪回声。
3. 陆观澜：同行者/货车/谎言试探、个性化玩笑、指点与第二日练习，取得姓氏的信任条件。
4. 医馆：主动问诊多分支、分级同意、基础包扎、欠诊金/杂活、保密/展示残片、协助验伤/举报/取证。
5. 无名尸：现有固定触发、传闻、检查和比对已可玩；程守义真实身份字段、证物归属变化、多方处置结果尚缺失。
6. 宁不平、顾清河、乔五：有静态定义，无本图对应的正常报案、拘押复核、证物交易与势力接触闭环。不能把调用通用NPC占位答话称为完成。
7. 岳寒声：第一二日正常路线不可接触；第四日可见性及破庙线待后续，不为本轮提前开放。
8. 全局：完整五维关系、通用话题重开、低经济兜底、收入、成长、离城，均未在本轮开发。当前会保留少量重复新闻/观察按钮，但不产出重复成长收益。

特别提示：**拘押后仍是内容断点，零银两缺少生存替代方案**。它们是待开发范围，不因本轮现有规则测试通过而消失。本轮仅纠正“文案声称发生但状态未发生”和已有流程自身的矛盾。
