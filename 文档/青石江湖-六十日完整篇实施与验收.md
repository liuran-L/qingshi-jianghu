# 六十日完整篇：实施与验收

更新：2026-09-05。本文与 README 描述当前代码；原设计稿提供素材，旧阶段报告记录历史版本。

## 时间线

沿用六十日。第 1–3 日保留雨夜盐引完整闭环，三结局可接续，错过盐案也可进入长篇。旧结案时间、盐货和许可期限归档；物品、身份、伤势、钱财、人情不重置。

第 4–57 日有 19 个关键事件：破庙、刺杀、传承、火灾、身份复核、遗孤、小蝉、外县道路、药铺、群议、河战、问案、旧债、追捕、药船、秩序、三账、最后的代价、证人之夜。第 58–60 日选择人生、核卷、落款。间隔可谋生、修习、治疗、补偿、听传闻、赶路；外县道路各选择花两天往返。

事件缺席有独立后果，未知结果不会立即公开。等待支付食宿，不足记债；伤病期间仍可能死亡。第 60 日 23:59 最迟定稿，不可无限跳过终局。时间统一结算，渲染、读档不重放。读取更早手动档按传统单机规则恢复该快照。

## 路线与通关

没有开局职业锁定。工作与事件积累五类经历，修习消耗经历、金钱和时间提升能力。帮助或伤害人物形成关系事务，信任影响立约、行商收入、从官机会和战斗助阵。

| 方向 | 生活 | 终局条件（均需对应经历至少 4） | 不同处置 |
| --- | --- | --- | --- |
| 侠行 | 护送、习武、助阵 | 群议获胜或民间秩序 | 凭三账公开，或付费护送；也可战斗、认拘 |
| 行商 | 核货积本、商货经营 | 建立商会且有 12 两 | 公开账目共同经营，或独占买卖 |
| 暗行 | 偷盗、身法、水路 | 水路且两种证据 | 散发证据降低追查，或卖秘密增加收入和追查 |
| 从官 | 抄册到核仓 | 路引、官档、追查低于 4 | 三账会审，证据不足有限追究，或妥协 |
| 行医 | 医馆工作、医术、药材 | 药账且至少一次医术训练 | 留下开诊，或带药远行 |

自动化每方向从头走通两条分支，共十条；另测远走、退隐、被拘、死亡。九种主终局标题下按处置、证据、人物生死、河流污染、钱债与追查给出事实结语。十条测试路径并非十套完全独立的主线剧本；主线事件共享，机会、规则结果及终局处置分化。

立约需经历、人物存活与信任，同路工作增加收益，跨路工作损失旧关系；解除旧约花 6 两，不足记债，不清空已有技能。追查可花一天补偿降 3 并增加 4 两债务。旧医馆债和长篇债各自可偿还。缺资本仍有核货、抄册等起步工作，避免经济锁死。

## 冲突与成长

战斗采用公开确定性判定：武力、修习、步法基础、可信助阵形成力量，伤势和疲劳减值，追查增加对方压力。行动预告伤害与致命风险，败而未死可继续，死亡截断时间和奖励。偷盗按身法与追查判定，不使用隐藏随机重掷。

原步法、医术技能树保留，长篇补齐授点路径，技能继续影响旅行与包扎。治疗先耗时，期间死亡不能获得治疗效果；包扎只延缓伤势恶化，不治毒或制造查案证据。

## 对话与美术

下方框显示角色名、台词和语气，逐句推进后开放下方选项，上方立绘随说话人切换；旁白不强行展示人物。地图、历史、存档、移动端响应布局保留。眼前、谋生、修习、旧事四组减少长菜单。

马三刀、苏晚棠、顾清河、宁不平、乔五、沈砚秋、岳寒声、陆观澜和主角共九张原创 SVG 半身立绘，统一纸色、墨线、淡彩晕染，以脸型、年龄、发式、服饰和道具区分。资源不引用外网，绑定独立于姓名认知，图片标签不泄露未知身份。生成源 tools/make-portraits.mjs，替换入口 lib/game/portraits.ts。

## 自动化与边界

GameState v6 新增 campaign schema 1。旧档整个字段缺失时迁移，字段部分缺失或矛盾则拒绝；校验经历训练守恒、证据来源、事件结果、时间、终局、立绘 ID 和序章归档。原关系、记忆、经济与成长测试保留。

campaign-flow.test.ts 新增 22 个测试实例：五方向十条初始至终局流程，每步存读和输入不可变性；旧档坏档、四种序章入口、缺席传闻、过期按钮、离场、立约改行、两棵技能树、死亡、战斗胜败、远走、六十日兜底。从实际通关捕获事件现场，另外遍历 85 个可用选择转换并验证存读。

最终检查命令 npm run check 与 npx tsc --noEmit。完整检查涵盖原有 136 个加新增 22 个测试，共 158 个，另含 lint、Web 构建和桌面前端构建。立绘已作拼图检查，本地预览确认可响应。

本次未进行真人长时试玩、完整浏览器点击验收或 Windows 原生安装包及 SQLite 实机验收，构建和规则测试不能替代这些检查。后续优先做真人节奏调优、场景背景、表情差分、更多日常人物互动及外县地图。当前没有宣称无限年限沙盒或全 NPC 自主模拟。
